# Стекование постоянного эффекта предмета

## Предложения

- [Стекование постоянного эффекта предмета](../proposals/2026-10-27_persistent-effect-stacking.md)

## Решения

- Действующий эффект ищется по типу, раундовой длительности и положительному остатку раундов. Объединение выполняется только когда и новое определение раундовое; постоянное определение предмета добавляется отдельным активным эффектом и не участвует ни в объединении, ни в отсчёте раундов — [effects.md](../../domain/effects.md#стекование).
- Минимум юнит-урона исправлен в этой же задаче: дошедший до цели удар всегда отнимает здоровье — [combat.md](../../domain/combat.md#f-урон). Отдельное предложение не заводится.
- Минимум юнит-урона не покрыт тестом: расчёт закрыт в сервисе боя, зона поражения и броски случайны, тестового шва без рефлексии нет. На текущих данных предметов случай недостижим.

## План

- [x] Объединять эффект предмета с действующим эффектом только при раундовой длительности обоих.
- [x] Не опускать юнит-урон ниже единицы.
- [x] Покрыть интеграционным тестом два эффекта одного типа с разными длительностями.

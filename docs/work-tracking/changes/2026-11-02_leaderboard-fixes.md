# Исправления таблицы рекордов

## Предложения

- [Исправления таблицы рекордов](../proposals/2026-10-14_leaderboard-fixes.md)

## Решения

- Показатель «Опыт» считается по накопленному опыту героя — [leaderboard.md](../../domain/leaderboard.md). Значение показателя хранится как `long`, как и опыт героя.
- Член перечисления показателей переименован в `EXPERIENCE`: он отдаёт опыт, и прежнее имя ему противоречило. Значение параметра в запросе меняется вместе с клиентом API, который перегенерируется.
- При равных значениях живой герой стоит выше погибшего при обоих порядках сортировки.
- Страница таблицы при повторном входе перезапрашивает данные с текущими фильтрами; сброс фильтров удалён как неиспользуемый.

## План

- [x] Считать «Опыт» по накопленному опыту и хранить значение как `long`.
- [x] Переименовать показатель в `EXPERIENCE` вместе с подписями «Опыт» и `xp`.
- [x] Ставить живого героя выше погибшего при равных значениях.
- [x] Сохранять фильтры при возврате на страницу таблицы.
- [x] Перегенерировать клиент API.

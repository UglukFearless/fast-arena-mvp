# Система брони

## Предложения

- [Защита зон бронёй](../proposals/2026-11-08_armor-zones.md)

## Цель

Защита зон героя в бою элементами брони.

## Ссылки на предметную область

- [`docs/domain/items.md`](../../domain/items.md) — тип брони.
- [`docs/domain/combat.md`](../../domain/combat.md) — расчёт урона в Фазе F, порядок модификаторов силы в Фазе E.

## Критерии приёмки

1. Элементы брони доступны в магазине и могут быть куплены героем.
2. Герой может экипировать элемент брони, если ни один из уже экипированных элементов не покрывает пересекающиеся зоны.
3. Экипировка конфликтующего элемента брони отклоняется с понятной причиной.
4. Удар по покрытой зоне уменьшается на оставшуюся прочность элемента брони до расчёта урона; прочность уменьшается на поглощённую силу. Удар, погашенный полностью, наносит нулевой урон и остаётся ударом. Элемент брони с нулевой прочностью сломан до конца приключения; между приключениями прочность восстанавливается.
5. Ответ раунда боя сообщает, сколько силы погашено и каким элементом брони.
6. После боя броня остаётся экипированной, а прочность переносится в следующий бой приключения — [adventure.md](../../domain/adventure.md#эпизод).

## Архитектурные заметки

- Защита брони — рантайм-состояние приключения, аналогичное оставшимся использованиям щита.
- Оценка защиты брони размещена на Фазе E жизненного цикла боя (модификаторы урона на уровне силы), до применения юнит-урона зоны.
- Слоты тела броня берёт из [Слотов экипировки](2026-11-04_equipment-slots.md).

## План

### Этап 1 — Предметная область и модель данных

- [ ] Определить структуру элемента брони: список защищаемых зон и значение защиты.
- [ ] Засеять начальный каталог элементов брони с покрытием зон и значениями защиты.

### Этап 2 — Магазин и поток экипировки

- [ ] Расширить магазин элементами брони.
- [ ] Включить экипировку/снятие брони в `HeroEquipmentService` с проверкой пересечения зон.
- [ ] Добавить backend-тесты на правила конфликта экипировки.

### Этап 3 — Интеграция с боем

- [ ] Инициализировать рантайм-состояние брони (оставшаяся защита) в начале боя из экипированной брони.
- [ ] Подключить поглощение защитой брони в Фазу E жизненного цикла боя.
- [ ] Расширить DTO раунда боя состоянием брони (оставшаяся защита по каждому элементу).
- [ ] Добавить backend-тесты на расход и поломку защиты брони.

### Этап 4 — Frontend

- [ ] Показывать экипированные элементы брони в UI экипировки героя.
- [ ] Показывать состояние брони (активна / сломана) в окне боя.

## Вне объёма

- Снижение урона зоны за единицу силы удара (Фаза F в `docs/domain/combat.md`): броня работает только через вычитание защиты из силы удара в Фазе E.

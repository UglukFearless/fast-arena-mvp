## Решения

- Раздел domain описывает целевое состояние игры и не зависит от реализации. Адресат — геймдизайнер, изложение в терминах игры.
- Раздел самодостаточен: ссылки ведут только внутрь раздела, чтобы его можно было перенести в другой проект.
- При расхождении кода с domain дефектен код.
- Документы раздела излагают утверждённые правила. Гипотезы лежат в domain/directions.md, который переезжает из work-tracking.
- Целевая модель раунда состоит из семи фаз A–G. Названия фаз не утверждены.
- Каждый документ раздела пишется заново через вопросы оператору. Ни старый текст, ни код источником истины не служат.
- Направления развития ведутся только игровые.
- directions.md открывается утверждением о статусе содержимого; каждое направление — подзаголовок и абзац прозы.
- Боевой потенциал участника называется боеспособностью. Прежнее имя величины — способность.
- Числа, меняемые ради баланса, лежат в domain/balance.md. Коэффициент, неотделимый от правила, остаётся в тексте правила.

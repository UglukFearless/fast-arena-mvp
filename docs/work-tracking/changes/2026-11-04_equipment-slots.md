# Слоты экипировки

## Предложения

- [Явный признак двуручного оружия](../proposals/2026-09-14_explicit-two-handed-weapons.md)

## Цель

Экипировка, в которой предмет занимает объявленный им набор слотов, а слоты героя задаются его телом и раскладкой.

## Решения

- Слоты героя лежат в одной таблице `HeroSlot` (`Id`, `HeroId`, `SlotKey`, `HeroItemCellId`); зоны, руки и карманы различает `SlotKey`, а не вид слота.
- Слот зоны несёт слаг карты тела: `<слаг тела>_BODY_<слаг зоны>`, например `HUMANOID_BODY_HEAD`. Ключи рук и карманов — общие для существ, привязку к телу получат вместе с индивидуальной раскладкой.
- Карта тела — данные в базе: слаг тела, у зоны — слаг, имя и число юнит-урона. Раскладка задаёт руки и карманы с числом экземпляров.
- Предмет объявляет занимаемое строками `ItemSlots` с повторами; экипировка занимает свободные слоты по ключу и освобождает все слоты ячейки при снятии.
- `HitZone` остаётся в коде боя до задачи [Универсальный участник боя](../proposals/2026-11-08_fight-participant.md).
- Загрузка предмета тянет `OccupiedSlots` отдельной цепочкой `Include`: без неё объявление слотов приходит пустым и экипировка отклоняется.

## План

### Этап 1 — Данные и схема

- [x] Убрать из `HeroSlot` поля `Type` и `BodyZoneId`, заменить их слагом `SlotKey`; ключом строки объявления предмета сделать `SlotKey`.
- [x] Заменить `HitZone` в карте тела на слаг зоны, имя и число юнит-урона.
- [x] Исключить прежние сущности слота героя и допустимых слотов предмета после перевода потребителей.
- [x] Описать схему в `ApplicationContext`, расширить цепочки `Include` в хранилищах героя и экипировки.
- [x] Создавать слоты героя при его создании: слоты тела по зонам карты тела, остальные по раскладке.

### Этап 2 — Экипировка

- [x] Занимать слоты по объявлению предмета, разрешая слаг зоны против карты тела носителя.
- [x] Освобождать все слоты ячейки при снятии.
- [x] Удалить проверки двуручности.
- [x] Покрыть тестами занятие нескольких слотов, чужое тело, нехватку экземпляра и снятие.

### Этап 3 — API и DTO

- [x] Отдавать слоты героя с ключами; отдавать занимаемые слоты предмета с повторами.
- [x] Перевести снятие на идентификатор ячейки и перегенерировать клиент.

### Этап 4 — Сиды

- [x] Засеять карту тела гуманоида, раскладку существа и занимаемые слоты существующих предметов.

## Вне объёма

- Другие тела, их зоны и слоты — направление [Тела существ](../../domain/directions.md), не правило.
- Карта поражения по существу: какие зоны есть у монстра и как выбирается зона удара.
- Броня: покрытие зон, конфликты и прочность — [Система брони](2026-08-02_armor-system.md); механика — [Защита зон бронёй](../proposals/2026-11-08_armor-zones.md).
- Универсальный участник боя и PvP — [Универсальный участник боя](../proposals/2026-11-08_fight-participant.md), [Кукла героя](../proposals/2026-11-08_hero-doll.md).

# Порядок эпитетов монстров

## Предложения

- [Порядок эпитетов монстров](../proposals/2026-10-25_monster-epithet-order.md)

## Решения

- Эпитет определяется разницей ранга вида и уровня монстра. Таблица диапазонов хранится массивом записей «от, до, формы эпитета» в порядке возрастания: границы диапазона и порядок перебора заданы явно, добавление эпитета — один элемент массива.
- `Dictionary` для этой таблицы не годится: порядок перебора он не гарантирует, а ключ-порог заставляет восстанавливать левую границу из соседнего ключа.
- Ранг вида ниже порога 12 поднимается до порога.
- Имя вида без эпитета не получает ведущего пробела.
- Тест обращается к публичному `CreateFromMoldAsync` с заглушкой `IMonsterMoldStorage`; рефлексия не используется.

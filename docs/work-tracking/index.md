# Раздел work-tracking

## Содержание

Учёт работы над проектом: предложения, изменения, roadmap и направления развития.

## Состав

| Документ | Содержание |
|---|---|
| [roadmap.md](roadmap.md) | Предложения и изменения, которыми предстоит заниматься |
| [directions.md](directions.md) | Направления развития без конкретной работы |
| [proposals/](proposals/) | Предложения |
| [changes/](changes/) | Изменения |

## Имя документа

`YYYY-MM-DD_name-in-kebab-case.md` в `proposals/` и `changes/`. Дата — день создания документа.

## Предложение

Идея, инициатива или технический долг. Изложение свободное: описание, мотивация, варианты, размышления.

Первый раздел — `## Изменения`: ссылки на изменения, выполняющие предложение. Пустой раздел — предложение не взято в работу. Второй раздел — `## Описание`.

## Изменение

Лог конечных решений по работе и её план. Отвергнутый вариант приводится, только когда принятое решение без него вызывает очевидный вопрос. Документ ведётся, пока идёт работа; после её завершения не актуализируется.

Первый раздел — `## Предложения`: ссылки на выполняемые предложения. Пустой раздел — изменение без предложения.

План ведётся в разделе `## План` чекбоксами `- [ ]` / `- [x]`. Нет пунктов — изменение планируется, есть открытые — в работе, все закрыты — выполнено.

Отменённое изменение помечается строкой `Отменено: <причина>` под заголовком; пометка важнее состояния плана.

## Roadmap

Ссылки на предложения и изменения, которыми предстоит заниматься. Реализованный пункт удаляется.

## Направления

Направления развития без конкретной работы. Направление, из которого созданы предложения, удаляется или сужается.

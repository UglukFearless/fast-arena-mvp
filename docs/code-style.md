# Стиль кода

Правила распространяются на C# и TypeScript, если не сказано иначе.

## Условный оператор

`if` пишется блочной формой с фигурными скобками. Исключение — ранний выход: скобки опускаются, выход переносится на следующую строку.

```csharp
if (condition)
{
    // some operations
    return value;
}
```

```csharp
if (isInvalid)
    return null;
```

## Комментарии

Комментарии пишутся на английском.

Смысл выражается именами и структурой кода. Комментарий допустим только когда сообщает то, чего в коде нет: причину неочевидного решения или внешнее ограничение, его продиктовавшее. Комментарий, пересказывающий код, удаляется.

# Раздел domain

## Адресат

Геймдизайнер.

## Содержание

Правила игры в задуманном виде: сущности игрового мира, механики, их числа и связи. Изложение ведётся в терминах игры.

Раздел самодостаточен: ссылки ведут только на документы раздела.

## Состав

| Документ | Содержание |

| [hero.md](hero.md) | Герой: характеристики, прогрессия, владение |
| [combat.md](combat.md) | Бой: монстр, схватка, награды и штрафы |

| [effects.md](effects.md) | Эффекты: типы, стекование, момент применения |

| [balance.md](balance.md) | Значения, меняемые ради баланса |
| [directions.md](directions.md) | Идеи и гипотезы развития игры |

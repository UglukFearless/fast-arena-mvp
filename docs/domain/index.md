# Раздел domain

## Адресат

Геймдизайнер.

## Содержание

Правила игры в задуманном виде: сущности игрового мира, механики, их числа и связи. Изложение ведётся в терминах игры.

Раздел самодостаточен: ссылки ведут только на документы раздела.

| [adventure.md](adventure.md) | Приключение: эпизоды и их типы |
| [hero.md](hero.md) | Герой: облик, характеристики, имущество, прогрессия, статистика боёв |

# Таблица рекордов

Таблица рекордов сравнивает героев всех игроков, живых и погибших, по одному показателю за раз. Герой попадает в таблицу сразу после создания.

## Показатели

- **Золото** — золото, которое у героя есть сейчас.
- **Победы** — число монстров, убитых героем.
- **Опыт** — опыт, накопленный героем, — [прогрессия](hero.md#прогрессия).

## Порядок и выборка

Игрок выбирает показатель и упорядочивает героев по нему по убыванию или по возрастанию. Из двух героев с равным значением живой считается лучше погибшего.

Игрок может оставить в таблице только живых или только погибших героев, а также только своих.

## Просмотр героя

Любого героя из таблицы можно открыть на просмотр. Просмотр показывает героя целиком — [герой](hero.md).

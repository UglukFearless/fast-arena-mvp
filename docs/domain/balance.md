## Бой с монстром

### Подбор монстра

Целевой ранг и уровень монстра не опускаются ниже 1.

| Сложность | Целевой ранг | Сдвиг уровня |
|---|---|---|
| Низкая | уровень героя − 5 | от −7 до +1 |
| Средняя | уровень героя | от −3 до +3 |
| Высокая | уровень героя + 5 | от −2 до +6 |

Вероятность вида пропорциональна его весу:

```
вес = 1 / (1 + 0.05 × (ранг вида − целевой ранг)²)
```

### Золото за победу

```
золото = база
       + случайное(0..4) × уровень монстра / уровень героя
       + случайное(0..9) × макс. здоровье монстра / макс. здоровье героя
```

Каждое слагаемое округляется вниз до целого.

| Уровень награды | База |
|---|---|
| Низкий | 10 |
| Средний | 20 |
| Высокий | 35 |

### Опыт за победу

```
опыт = 40 × уровень монстра / уровень героя × макс. здоровье монстра / макс. здоровье героя
```

Результат округляется вниз до целого.

### Порог уровня

Опыт, необходимый для уровня L + 1:

```
опыт = 100 × (1 + 2 + … + L)
```

Пороги: 100 для второго уровня, 300 для третьего, 600 для четвёртого и так далее.

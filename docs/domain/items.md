# Предметы

Предмет — вещь игрового мира. У предмета есть имя, описание, изображение, базовая стоимость и тип. Предмет может складываться в стопку с такими же предметами. Каталог предметов — [баланс](balance.md).

## Типы

- **Деньги** — золото, средство оплаты в магазине — [экономика](economy.md).
- **Зелье** — расходуемый предмет, используемый в бою — [бой](combat.md#раунд).
- **Оружие** — снаряжение, усиливающее удар владельца.
- **Щит** — снаряжение, гасящее удары по владельцу.
- **Броня** — снаряжение, защищающее зоны тела.
- **Прочее** — добыча без применения, которую продают в магазине.

## Снаряжение

Оружие, щит и броня — снаряжение, которое надевают — [инвентарь и экипировка](inventory.md). Надетое снаряжение действует через постоянные эффекты: они активны весь бой, пока предмет надет, — [эффекты](effects.md).

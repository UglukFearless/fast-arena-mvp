# Инвентарь и экипировка

## Инвентарь

Инвентарь — все предметы, принадлежащие владельцу, в том числе надетые. Предметы, складывающиеся в стопку, хранятся одной стопкой с количеством; остальные — каждый отдельно. Свойства предметов — [предметы](items.md).

## Экипировка

Экипировка — предметы инвентаря, надетые в слоты экипировки. В слот помещается один предмет; в какие слоты предмет надевается, задаёт сам предмет.

Слоты экипировки — правая рука, левая рука и три кармана. Правая рука держит оружие, левая — щит; двуручное оружие занимает обе руки. В карманы кладутся зелья для боя — [бой](combat.md#раунд).

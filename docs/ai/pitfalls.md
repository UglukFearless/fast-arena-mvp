# Подводные камни

Запись добавляется после реального инцидента.

- **Миграции EF не генерируются, не запускаются и не коммитятся.** Как схема попадает в базу — раздел «Схема базы данных» в [backend.md](../tech/backend.md).
- **Новое вложенное поле в ответе API приходит пустым без ошибки.** Что для него расширяется — раздел «Модели и маппинг» в [backend.md](../tech/backend.md).
- **Имя программной сущности — не доменный термин.** Enum, тип, поле, свойство суть материализация принятого решения, а не понятие предметной области. Совпадение имени с доменным понятием не делает их одним и тем же; в документацию предметной области они не попадают.
- **Документы `docs/work-tracking/` — не текущее поведение.** Текущее поведение описывают разделы domain и tech.
- **Дочерние строки сида добавляются явно и держат id константами.** Строки, висящие только на навигации удалённой или заменённой сущности, в базу не попадают; объекты, построенные в свойствах сида, дают новые `Guid.NewGuid()` при каждом обращении.
- **Правка файла через PowerShell портит кириллицу.** `Get-Content`/`Set-Content` с неверной кодировкой переписывают русский текст в `?` или символ замены. Файлы правятся редактором, не строковыми операциями скрипта.

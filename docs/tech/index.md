# Раздел tech

## Адресат

Разработчик или AI-агент, меняющий код проекта.

## Содержание

Устройство кода: компоненты системы и их взаимодействие, внутреннее устройство backend и frontend, окружение запуска.

Раздел описывает реализацию, в том числе реализацию доменных явлений: где и каким механизмом они воплощены в коде.

Раздел описывает только действующую реализацию. Намеченная работа ведётся в [work-tracking](../work-tracking/index.md).

# Правила для агента

## Чтение перед задачей

Любая задача начинается с чтения:

- [README.md](README.md) — что за проект и как он запускается;
- [docs/ai/index.md](docs/ai/index.md) — состав раздела о работе агента;
- [docs/ai/workflow.md](docs/ai/workflow.md) — рабочий цикл;
- [docs/ai/pitfalls.md](docs/ai/pitfalls.md) — ловушки проекта.

## Действия по явному указанию

Агент не выполняет без письменного указания оператора:

- любые операции git — commit, push, branch, merge, rebase, reset, stash, tag;
- запуск ревью;
- drop, create и reset базы данных.

Агент предлагает действие и ждёт.

## Авторство коммитов

Агент не указывает себя соавтором коммита. Строка `Co-Authored-By` добавляется только по явному указанию оператора.

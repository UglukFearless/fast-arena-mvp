# Создание предложения

Перед выполнением прочитать docs/work-tracking/index.md.

1. Получить от оператора суть предложения. Неясная суть уточняется вопросом.
2. Создать документ в `docs/work-tracking/proposals/`. Имя — по индексу раздела: дата текущая, название на английском. Содержимое: заголовок, пустой раздел `## Изменения`, раздел `## Описание` с изложением. Текст излагает сказанное оператором; собственные размышления и варианты не добавляются.

Git-операции не выполняются.

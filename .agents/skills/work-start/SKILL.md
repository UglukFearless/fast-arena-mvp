# Взятие в работу

Перед выполнением прочитать docs/work-tracking/index.md.

1. Получить от оператора название изменения и выполняемые предложения; предложений может не быть. Неясное уточняется вопросом.
2. Создать документ в `docs/work-tracking/changes/`. Имя — по индексу раздела: дата текущая, название на английском. Содержимое: заголовок и раздел `## Предложения` со ссылками на предложения.
3. В раздел `## Изменения` каждого предложения добавить ссылку на изменение.
4. Пункты roadmap со ссылками на выполняемые предложения заменить одним пунктом со ссылкой на изменение. Если таких пунктов нет — добавить пункт со ссылкой на изменение.

Текст ссылки — заголовок документа. Ссылки относительные: из roadmap — `changes/<файл>`, из изменения — `../proposals/<файл>`, из предложения — `../changes/<файл>`. Git-операции не выполняются.
